Reporting from CI

The gate keeps running where it runs now. These flags post the verdict here afterwards; the exit code is unchanged, so a regression still fails the job. 

arbiter gate evals/suite.yaml \
  --store .arbiter/runs.sqlite \
  --publish {{ settings.base_url }} \
  --publish-token $ARBITER_HUB_TOKEN

Or without the CLI, if you would rather post it yourself:

curl -sS -X POST {{ ingest_url }} \
  -H "Authorization: Bearer $ARBITER_HUB_TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"result\": $(cat arbiter-result.json)}"
